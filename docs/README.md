## この基盤を貫く原則

**一度だけ推論し、結果を凍結する。**

投稿本文は自然言語であり、そのままでは検索も集計もできない。取り込み時に一度だけ構造化抽出を行い、結果を確定値としてDBへ書き込む。以降の検索・集計・レポート生成は、この確定値に対する決定論的な処理として実行する。

推論が発生する箇所を1点に限定することで、下流のすべてが検証可能になる。

## 読む順番

初めて読む場合は requirements → design → roadmap の順。個別の「なぜこの技術を選んだか」は該当ADRを参照。
